# CineVerse — Bài thi Thiết kế Web

Website giới thiệu và khám phá phim bằng tiếng Việt, thiết kế theo phong cách điện ảnh hiện đại, nền tối và màu nhấn xanh neon.

## Chức năng
- Bố cục responsive cho máy tính, máy tính bảng và điện thoại.
- Giao diện responsive, điều hướng bằng liên kết neo và chọn thể loại qua các liên kết.
- Mở/đóng phần mô tả từng phim bằng thẻ HTML `<details>` (không cần JavaScript).
- CSS Grid/Flexbox, CSS Variables và HTML5 semantic.

## Chạy thử
Mở file `Trần_Tiến_Đạt-125000955.html` bằng trình duyệt. Bản này đã loại bỏ hoàn toàn JavaScript. Vì HTML/CSS thuần không thể thực hiện xử lý động, tìm kiếm/lọc/sắp xếp tự động, lưu yêu thích, hộp thoại động và gửi form không còn hoạt động như bản JavaScript.

## Triển khai GitHub Pages
1. Tạo repository công khai với tên đúng định dạng yêu cầu của giảng viên: `Ten_Ho_MSSV` (thay bằng thông tin của bạn).
2. Upload `Trần_Tiến_Đạt-125000955.html`, `style.css`, `PROMPT_LOG.md` và `README.md` lên nhánh `main`, ở thư mục gốc.
3. Mở **Settings → Pages**.
4. Chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/ (root)`, rồi nhấn **Save**.
5. Chờ GitHub tạo URL Pages, mở URL trên cả máy tính và điện thoại để kiểm tra trước khi nộp.

## Lưu ý trung thực khi trình bày
- Đây là website mẫu tĩnh; tên phim, mô tả và điểm đánh giá chỉ dùng để minh họa.
- Yêu thích chỉ lưu trong bộ nhớ của trang, chưa đồng bộ và sẽ mất khi tải lại.
- Form email chưa kết nối backend, không gửi hoặc lưu email lên máy chủ.
- Trước khi nộp, hãy rà soát `PROMPT_LOG.md` và sửa để phản ánh chính xác quá trình làm bài thực tế.
