# CineVerse — HTML + CSS (không JavaScript)

Website giới thiệu và khám phá phim bằng HTML5 và CSS3 thuần.

## Chạy website
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt hoặc tải hai file lên GitHub repository.
3. Đảm bảo `index.html` và `style.css` nằm cùng thư mục.

## Thành phần
- Giao diện CineVerse tông tối, điểm nhấn xanh neon, responsive cho máy tính và điện thoại.
- Trang chủ/hero, phim nổi bật gồm 6 thẻ, thể loại, hồ sơ phim mở rộng bằng thẻ HTML `<details>`, phần giới thiệu, đánh giá minh họa, liên hệ email và nút quay về đầu trang.
- Điều hướng bằng liên kết neo, không cần JavaScript.

## Giới hạn khi không dùng JavaScript
Tìm kiếm/lọc/sắp xếp trực tiếp, danh sách yêu thích lưu trạng thái, popup tương tác và gửi form tự động không thể hoạt động như ứng dụng động nếu chỉ có HTML/CSS. Website này thay bằng liên kết đến hồ sơ phim và mục nội dung mở rộng thuần HTML. Form đăng ký được thay bằng liên hệ email để tránh giả lập gửi dữ liệu. Nội dung phim và đánh giá là minh họa cho bài tập.
