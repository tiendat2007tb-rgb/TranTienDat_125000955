# Prompt Log — CineVerse

## Yêu cầu cập nhật
- Mở rộng nội dung và chiều dài trang web.
- Giữ phong cách điện ảnh hiện đại, nền tối và điểm nhấn xanh neon.
- Chỉ sử dụng HTML và CSS, không dùng JavaScript.

## Cách thực hiện
- Dùng semantic HTML: header, nav, main, section, article, details/summary và footer.
- Dùng CSS Grid/Flexbox, hiệu ứng hover nhẹ, responsive breakpoints và hỗ trợ prefers-reduced-motion.
- Thay các nút cần JavaScript bằng liên kết neo và nội dung mở rộng HTML.
- Không nhúng script hoặc thư viện JavaScript bên ngoài.
